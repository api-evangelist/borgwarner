# BorgWarner

> BorgWarner Inc. (NYSE: BWA) is a global automotive supplier founded in 1928 and
> headquartered in Auburn Hills, Michigan. It designs and manufactures propulsion
> systems, thermal management, battery systems, charging solutions and power
> electronics for combustion, hybrid and electric vehicles, and has extended the
> same power-conversion and energy-storage engineering into industrial and data
> center power. BorgWarner is a hardware supplier: as of 2026-09-04 it publishes
> no public API, no developer portal, and no machine-readable API contract.

## Status for agents

- There is **no BorgWarner API** an agent can call. No OpenAPI, AsyncAPI, GraphQL SDL,
  gRPC .proto or WSDL is published anywhere on borgwarner.com.
- `api.borgwarner.com`, `developer.borgwarner.com` and `docs.borgwarner.com` do not
  resolve in DNS. There is no GitHub organization and no client library in any public
  package registry.
- The one API-shaped surface on the domain is the Progress Sitefinity CMS OData v4
  service at `https://www.borgwarner.com/api/default`, which returns HTTP 401 to
  anonymous callers. It is the website platform's own service, not a product API.
- BorgWarner does integrate with partners machine-to-machine, but over **EDI**
  (X12 or EDIFACT) through the supplier program, not over HTTP APIs. The implementation
  guidelines are issued to onboarded suppliers.
- Do not attempt to synthesise a BorgWarner API contract. There is nothing to call.
